# 接口版本变动

当前版本：PBOXQT1.0V202202.00.005

| 变动版本 | 变动内容 |
| --- | --- |
| PBOXQT1.0V202101.03.000 | [on_order_response()](https://ptradeapi.com/index.html#on_order_response) 主推信息中新增entrust_type、entrust_prop字段； 修复信用交易接口兼容问题； [get_price()](https://ptradeapi.com/index.html#get_price) 、 [get_history()](https://ptradeapi.com/index.html#get_history) 支持周频(1w)行情获取； 由于行情源不再更新维护， [get_fundamentals()](https://ptradeapi.com/index.html#get_fundamentals) 接口去除share_change表； |
| PBOXQT1.0V202101.04.000 | 修复 [get_all_orders()](https://ptradeapi.com/index.html#get_all_orders) 获取特定委托状态报错问题，status字段返回数据类型从int改为str； [on_order_response()](https://ptradeapi.com/index.html#on_order_response) 、 [on_trade_response()](https://ptradeapi.com/index.html#on_trade_response) 支持获取非本策略交易的主推信息(需券商配置默认不推送)，且on_order_response推送非本策略交易的主推信息时不包含order_id字段； 相关功能优化； |
| PBOXQT1.0V202101.05.000 | 信用账户支持 [ipo_stocks_order()](https://ptradeapi.com/index.html#ipo_stocks_order) 接口调用； 由于行情源返回信息不包含， [get_fundamentals()](https://ptradeapi.com/index.html#get_fundamentals) 获取growth_ability、profit_ability、eps、operating_ability、debt_paying_ability表不再返回company_type字段； 由于上交所债券业务规则变更，调用 [debt_to_stock_order()](https://ptradeapi.com/index.html#debt_to_stock_order) 接口对上海市场可转债进行转股操作时需传入可转债代码，不再传入转股代码； |
| PBOXQT1.0V202101.06.000 | 新增 [get_user_name()](https://ptradeapi.com/index.html#get_user_name) API接口，用于获取登录终端的资金账号； 研究中 [get_price()](https://ptradeapi.com/index.html#get_price) 新增支持获取周线数据； [get_snapshot()](https://ptradeapi.com/index.html#get_snapshot) 新增支持获取XBHS行业版块市场数据； [send_qywx()](https://ptradeapi.com/index.html#send_qywx) 新增toparty(发送对象为部门)、touser(发送内容为个人)、totag(发送内容为分组)入参； |
| PBOXQT1.0V202101.07.000 | [get_snapshot()](https://ptradeapi.com/index.html#get_snapshot) 新增wavg_px(加权平均价)、px_exchange_rate(涨跌幅)出参； 可转债回测业务新增支持T+0； 新增支持融资融券回测业务， [融资融券专用函数](https://ptradeapi.com/index.html#融资融券专用函数) 中暂只支持 [margin_trade()](https://ptradeapi.com/index.html#margin_trade) 接口； |
| PBOXQT1.0V202101.08.000 | [initialize](https://ptradeapi.com/index.html#initialize) 对部分API接口调用进行限制，仅 [initialize](https://ptradeapi.com/index.html#initialize) 可调用接口说明中的API可在initialize函数内使用； [before_trading_start](https://ptradeapi.com/index.html#before_trading_start) 和 [after_trading_end](https://ptradeapi.com/index.html#after_trading_end) 对两融委托API接口调用进行限制； 修复仅单笔成交订单时调用get_trades()返回格式有误问题； 修复交易场景中获取当日K线14:58、14:59分价格为0问题； [send_email()](https://ptradeapi.com/index.html#send_email) 发送邮件信息新增path(附件路径)、subject(邮件主题)入参； 新增 [get_cb_list()](https://ptradeapi.com/index.html#get_cb_list) 获取可转债列表； 新增 [get_deliver()](https://ptradeapi.com/index.html#get_deliver) 获取历史交割单信息； 新增 [get_fundjour()](https://ptradeapi.com/index.html#get_fundjour) 获取历史资金流水信息； 新增 [get_research_path()](https://ptradeapi.com/index.html#get_research_path) 获取研究路径； [get_market_detail()](https://ptradeapi.com/index.html#get_market_detail) 新增支持在回测、交易场景中调用； |
| PBOXQT1.0V202101.09.000 | [get_market_detail()](https://ptradeapi.com/index.html#get_market_detail) 限制仅 [before_trading_start](https://ptradeapi.com/index.html#before_trading_start) 和 [after_trading_end](https://ptradeapi.com/index.html#after_trading_end) 中使用； [get_snapshot()](https://ptradeapi.com/index.html#get_snapshot) 新增返回hsTimeStamp(快照时间戳)字段；对接L2行情买卖一档新增返回委托队列； [ipo_stocks_order()](https://ptradeapi.com/index.html#ipo_stocks_order) 新增black_stocks(新股/债黑名单)入参； [on_order_response()](https://ptradeapi.com/index.html#on_order_response) 新增返回error_info(错误信息)字段； |
| PBOXQT1.0V202201.00.000 | [get_individual_transcation()](https://ptradeapi.com/index.html#get_individual_transcation) 新增返回buy_no(叫买方编号)、sell_no(叫卖方编号)、trans_flag(成交标记)、trans_identify_am(盘后逐笔成交序号标识)、channel_num(成交通道信息)字段； [get_margin_contract()](https://ptradeapi.com/index.html#get_margin_contract) 新增返回compact_interest(合约利息金额)、real_compact_interest(日间实时利息金额)、real_compact_balance(日间实时合约金额)、real_compact_amount(日间实时合约数量)字段； [get_price()](https://ptradeapi.com/index.html#get_price) 、 [get_history()](https://ptradeapi.com/index.html#get_history) 新增支持：1月(mo)、1季度(1q)、1年(1y)频率行情获取； [set_commission()](https://ptradeapi.com/index.html#set_commission) 中type字段新增支持传入"LOF"类型； [get_individual_entrust()](https://ptradeapi.com/index.html#get_individual_entrust) 和 [get_individual_transcation()](https://ptradeapi.com/index.html#get_individual_transcation) 返回内容中hq_px字段值缩小1000倍，返回为真实价格； 新增支持期货日盘回测功能、期货日盘交易功能(对接UFT柜台)，期货API接口详见量化帮助文档 [期货专用函数](https://ptradeapi.com/index.html#期货专用函数) 模块； 新增 [get_tick_direction()](https://ptradeapi.com/index.html#get_tick_direction) 获取分时成交行情； 新增 [get_sort_msg()](https://ptradeapi.com/index.html#get_sort_msg) 获取版块、行业的涨幅排名； 新增 [permission_test()](https://ptradeapi.com/index.html#permission_test) 权限校验； |
| PBOXQT1.0V202201.01.000 | 修复委托状态类型不一致问题， [get_orders()](https://ptradeapi.com/index.html#get_orders) 、 [get_all_orders()](https://ptradeapi.com/index.html#get_all_orders) 以及 [Order](https://ptradeapi.com/index.html#Order) 对象中的委托状态字段数据类型从int统一为str； 新增 [get_trade_name()](https://ptradeapi.com/index.html#get_trade_name) 获取交易名称； [tick_data](https://ptradeapi.com/index.html#tick_data) 中可调用接口完善； 研究中 [get_stock_name()](https://ptradeapi.com/index.html#get_stock_name) 、 [get_stock_info()](https://ptradeapi.com/index.html#get_stock_info) 新增支持获取可转债、ETF、LOF品种； [get_history()](https://ptradeapi.com/index.html#get_history) 新增fill(填充类型)入参； [get_price()](https://ptradeapi.com/index.html#get_price) 、 [get_history()](https://ptradeapi.com/index.html#get_history) 新增支持：5分钟(5m)、15分钟(15m)、30分钟(30m)、60分钟(60m)、120分钟(120m)频率行情获取； |
