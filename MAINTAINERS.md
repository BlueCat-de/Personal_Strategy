# Maintainers

## Project Maintainer

- [BlueCat-de](https://github.com/BlueCat-de)

Maintainers review releases, security reports, architecture changes, and
quantitative-research methodology.

Project decisions prioritize:

1. point-in-time correctness;
2. reproducible execution assumptions;
3. honest in-sample and out-of-sample reporting;
4. protection of credentials and licensed market data;
5. small, reviewable changes.
